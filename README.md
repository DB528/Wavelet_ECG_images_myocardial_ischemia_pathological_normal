# Wavelet_ECG_images_myocardial_ischemia_pathological_normal
This repository contains a collection of images generated using the wavelet transform applied to the ST segment (sST) of electrocardiographic (ECG) signals. The dataset includes both reference (normal) cases and pathological records associated with myocardial ischemia.

The data were extracted from multiple ECG recordings available on PhysioNet, specifically from the European ST-T Database (EDB). This database provides annotated ECG signals with documented ST and T wave changes, including episodes related to myocardial ischemia, making it a widely used benchmark for biomedical signal analysis.

The purpose of this repository is to support the study, analysis, and development of automated methods for detecting and classifying cardiac abnormalities, particularly those related to ST segment deviations, using time-frequency representations.

Data source: https://physionet.org/content/edb/1.0.0/
